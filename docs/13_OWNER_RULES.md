## Role rules of the central protocol that apply here
Owner decides behaviour/scope/priorities; reviewer analyses and approves; coder implements only the approved scope, makes no commits/tags/merges/pushes without release; outside the approved area the project is read-only.
Global instructions additionally: multi-agent workflow only on explicit request; FOREIGN files are not changed; strictest rule wins on conflict.
