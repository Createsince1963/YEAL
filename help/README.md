# Yeal manuals / Handbücher

The manuals are self-contained HTML files and work locally without an internet connection.

Die Handbücher sind eigenständige HTML-Dateien und funktionieren lokal ohne Internetverbindung.

- [Language selection / Sprachauswahl](index.html)
- [Deutsches Benutzerhandbuch](manual-de.html)
- [English user manual](manual-en.html)

Open `index.html` in a browser, or follow one of the language links above when viewing the repository on GitHub.

`manual.css` contains the shared responsive, dark-mode, and print styling. The manuals use only local assets from this repository.
