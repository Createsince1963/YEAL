# Release Upload Folder

This folder is used for versioned EXE uploads created by `exe_built.bat`.

Typical contents:

- `Yeal-v0.8.14.exe`
- `Yeal-v0.8.14.exe.sha256`
- `Yeal-v0.8.14-portable.zip`

The naming matches the current `VERSION` file and is intended for GitHub release upload or manual backup.
